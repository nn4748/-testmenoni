# ذاكرلي

تطبيق ويب يحوّل ملزمة المحاضرة (PDF أو نص) إلى ملخص وبطاقات مراجعة واختبار، باستخدام Claude.

> شرح التشغيل والنشر الكامل يجي في المرحلة الأخيرة.

## تشغيل سريع

```bash
npm install
cp .env.example .env.local   # وحط مفتاح ANTHROPIC_API_KEY
npm run dev
```

بعدها افتح http://localhost:3000
